# LAB01 – MySQL

## Présentation
Ce projet contient les travaux pratiques réalisés dans le cadre de l'apprentissage de MySQL.

## Objectifs
- Installer et configurer MySQL.
- Créer et gérer une base de données.
- Créer des tables et manipuler les données.
- Utiliser les requêtes SQL.
- Gérer les index et les performances.
- Gérer les utilisateurs et les privilèges.
- Exporter et importer les données.

## Organisation du projet

- `sql/` : fichiers contenant les requêtes SQL de chaque partie.
- `screenshots/` : captures d'écran des manipulations réalisées.
- `exports/` : fichiers d'exportation de la base de données.
- `lab1_export_import.txt` : commandes utilisées pour l'exportation et l'importation.

## Environnement
- MySQL Server 8.4
- MySQL Workbench
- Windows 11

## Conclusion
Ce TP m'a permis de découvrir les principales fonctionnalités de MySQL et de pratiquer la gestion des bases de données.
